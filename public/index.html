opendb-store examples

Each example is one small page with its own main.js. The code imports the library the same way your project would.

  • BasicsSave, read, check, and remove a value. It survives a page reload.
  • ExpiryGive a value a lifetime and watch it disappear by itself.
  • Theme sync across tabsSubscribers hear about changes from this tab and from your other tabs.
  • API response cacheServe repeat requests from storage and refetch only when the data is stale.
  • Form autosaveType, then reload. The draft stays in this tab until you submit it.
  • Cookie consentRemember a choice for a year in a cookie that your server can also read.
  • Shopping cartKeep a cart between visits and query it with the helpers from opendb-store/query.
  • Per-user data and logoutEach user gets a namespace, so logging out removes only that user's data.
  • Schema migrationChange your data shape without breaking returning users. Old entries upgrade when first read.
  • Error handlingOperations never throw. Every failure returns a result and reaches one handler.
  • Storage size debuggerSee how much each storage is using, and which keys are the largest.
